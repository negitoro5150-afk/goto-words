# GOTO WORDS

後藤さん専用のiPhone向け英単語PWA v1です。初期データは92語。

## 入っている機能
- カードをタップして英語→日本語を表示
- 左右スワイプ
- 「覚えた」「苦手」の履歴を端末内に保存
- 苦手だけ復習
- 英→日 / 日→英
- シャッフル
- 単語検索
- アプリ内から単語追加
- JSONバックアップ/復元
- オフライン対応

## iPhoneのホーム画面に入れる
PWAとしてインストールするにはHTTPSで公開する必要があります。
GitHub Pages / Netlify / Vercelなどに、このフォルダの中身をそのまま配置してください。
公開URLをiPhoneのSafariで開き、「共有」→「ホーム画面に追加」でGOTO WORDSがアプリのように起動します。

## ChatGPTからの自動追加について
v1はローカル保存です。ChatGPTから「単語帳に追加」で直接反映するには、
1. クラウドDB
2. 認証付きの追加API
3. ChatGPT側のカスタム連携
が必要です。UIと単語データ構造は、その拡張をしやすい形にしてあります。
