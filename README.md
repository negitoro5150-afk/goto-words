# GOTO WORDS

後藤さん専用のiPhone向け英単語PWA v2です。初期データは92語。

## 入っている機能
- カードをタップして英語→日本語を表示
- 左右スワイプ
- 「覚えた」「苦手」の履歴を端末内に保存
- 苦手だけ復習
- 最近追加20語だけでカード学習・一覧表示（追加日時の新しい順、同日時はIDの大きい順）
- 英→日 / 日→英
- シャッフル
- 単語検索
- アプリ内から単語追加
- JSONバックアップ/復元
- オフライン対応

## iPhoneのホーム画面に入れる
PWAとしてインストールするにはHTTPSで公開する必要があります。
GitHub Pages / Netlify / Vercelなどに、このフォルダの中身をそのまま配置してください。
公開URLをiPhoneのSafariで開き、「共有」→「ホーム画面に追加」でGOTO WORDSがアプリのように起動します。

## ChatGPTからの自動追加について
起動時とネットワーク復帰時にSupabaseのpublic.wordsを読み取ります。公開用publishable keyだけを使用し、ブラウザからデータベースには書き込みません。

学習状態は既存のgotoWords.v1保存領域を引き継ぎ、front（前後の空白除去・小文字化）をキーにstatsByFrontへ移行します。クラウドのIDが変わっても覚えた・苦手・回答回数・最終回答日時を維持します。クラウドと同じ単語の意味は更新し、端末で追加した単語は残します。バックアップはv1/v2とも読み込めます。

通信失敗時は端末のデータを維持し、words.jsonから未登録の初期単語を補います。初回は埋め込みの92語も利用できます。service workerはv2の画面とwords.jsonを保存し、旧キャッシュを削除します。
